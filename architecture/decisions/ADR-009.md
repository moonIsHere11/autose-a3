# ADR-009: Safety by budgets, structural bounds and untrusted-text quarantine

**Status:** Accepted (2026-11-21)

## Context
Anyone can open an issue, and its text reaches an LLM. A malicious issue can try to make an agent
leak the API key, push to `main`, merge, open PRs elsewhere or loop forever. Free-tier limits
(429), model overload (503) and slow calls (~20 s for Gemma) can stall a run. GitHub-hosted jobs
are killed after 6 hours by default, which is far too long to wait for a stuck agent.

## Decision
- **Quarantine:** only the Analyst (read-only) and the Reviewer (read-only) see raw issue text,
  wrapped in `<untrusted_issue>` tags and introduced as data, not instructions (spotlighting). The
  Builder and Tester, the agents that can write, see only gate-checked artifacts.
- **No credentials in reach:** API key only in the harness process; GitHub token only in
  deterministic steps; `run` in `docker --network none`; `persist-credentials: false` (ADR-005).
- **Never merge:** no job has a merge step or a token that can bypass branch protection; `main` is
  protected; `finalize` posts "a human decides".
- **Budgets:** step cap per agent (16 actions, `AUTOSE_MAX_STEPS`), per-run token budget, per-call timeout with
  exponential backoff on 429/503 then model fallback, 120 s per sandbox command, `timeout-minutes`
  on every job. Attempt budgets for loops (ADR-002).
- **Stuck stages** end the run with the reason written into the stage's artifact and the ledger.

## Alternatives considered
- **Prompt-only defence** ("ignore instructions in the issue"). Weak on its own; kept only as one
  layer. Rejected as the main defence.
- **LLM classifier that screens issues for injection.** Another model to fool, and false positives
  block real issues. Rejected.
- **Only maintainers' issues run.** Already done via triggers (ADR-010), but a maintainer can label
  a malicious user's issue, so the content is still untrusted.

## Consequences
- The worst outcome of a successful injection is a bad diff on a branch, which the gates, reviewer
  and human still have to accept. It cannot leak secrets or reach `main`.
- An injection can still pass from the issue into the spec text that the Builder reads. Planned
  check: one experiment issue carries an injection attempt; we report whether it reached the diff.
- Budgets can stop a run that would have succeeded with more steps; such stops are logged in the
  ledger.
