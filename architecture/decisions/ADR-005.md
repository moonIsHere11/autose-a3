# ADR-005: Own small harness with per-role tool allowlists, a network-less credential-free sandbox, and gh/REST only in deterministic steps

**Status:** Accepted (2026-11-21)

## Context
Agents need to read code, edit files and run tests. Whatever runs an agent's commands could, if
the agent is tricked, exfiltrate secrets or push code. GitHub-hosted runners have Docker. Gemma via
the Gemini API does not support native function calling reliably, so SDKs that rely on it (Claude
Agent SDK, OpenAI Agents SDK) do not fit our model choice. mini-swe-agent shows a text-action loop
works with any model.

## Decision
- A ~300-line Python harness drives every LLM role with a text/JSON action protocol (one action per
  turn, mini-swe-agent style). Tools: `read`, `ls`, `grep`, `write`, `replace`, `run`, `done`.
  Each role has an allowlist (ADR-001); a tool outside it is refused by the harness.
- `write`/`replace` enforce the role's write scope (`tinydb/` or `tests/autose/`). The gate checks
  the final diff again and rejects anything touching other paths, `.github/` or `.autose/`.
- **`run` executes in `docker run --network none`**, with no API key and no GitHub token in its
  environment, CPU/memory/PID limits and a 120 s timeout. The Reviewer's sandbox mounts the repo
  read-only with a scratch `/tmp`.
- The API key exists only in the harness process. The GitHub token exists only in deterministic
  steps (`gate`, `ship_*`, `finalize`, review posting). The LLM never holds a credential.
- GitHub is driven with the `gh` CLI and REST from those deterministic steps. No MCP server.
- Agent jobs check out with `persist-credentials: false`, so no token is left in `.git/config`.

## Alternatives considered
- **GitHub MCP server for the agents.** Convenient, but no agent needs to call GitHub. Giving
  them one only adds attack surface. Rejected.
- **Unrestricted shell on the runner (plain mini-swe-agent).** Simple, but the shell inherits the
  runner's environment and network: an injected `curl` could leak the key. Rejected.
- **Claude Agent SDK / claude-code-action.** Mature tool permissions, but tied to Claude models,
  and we have only a free Gemini key. Rejected.

## Consequences
- Least privilege is enforced by construction, not by prompt: an injected instruction cannot reach
  the network or a credential from inside the sandbox.
- We own the harness's bugs. The text protocol can fail to parse; the harness answers with a
  format error and counts it against the step cap.
- Docker adds image pull/build time (~20-40 s per job).
