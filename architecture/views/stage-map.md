# Stage map

Workers use `gemini-3.5-flash-lite` (fallbacks `gemini-3.1-flash-lite`, `gemma-4-31b-it`; ADR-011, which supersedes ADR-006's Gemma choice).
The Reviewer uses `gemini-3-flash-preview` (fallback `gemini-3.5-flash`). Every check below is code; no LLM certifies its own stage.

| # | Stage | Agent / component | Model | Inputs (and deliberately withheld) | Artifact | Check (code) | On failure |
|---|---|---|---|---|---|---|---|
| 1 | Requirements | Analyst (job `build`) | gemini-3.5-flash-lite | Raw issue wrapped in `<untrusted_issue>`, condensed A1 requirements-spec skill, read-only repo. | `spec.md` | Spec parses; at least 1 `AC-n`; every AC has Given/When/Then; fuzzy-word lint (fast, easy, robust, ...) on ACs. | Retry with gate feedback (2 retries), then stop with reason in `spec.md`. |
| 2 | Design | Analyst (job `build`) | gemini-3.5-flash-lite | `spec.md`, A2 `ARCHITECTURE.md`, read-only repo. | `design.md` | Changes table present; each `file::function` exists per AST, or is marked NEW. | Retry with feedback (2 retries), then stop. |
| 3 | Implementation | Builder (job `build`) | gemini-3.5-flash-lite | `spec.md`, `design.md`, harness-extracted source of the symbols `design.md` names, repo. Withheld: raw issue (injection quarantine). | `diff.patch` | Diff non-empty; touches only `tinydb/`; `compileall`, `import tinydb` and `mypy tinydb` pass in sandbox. | Retry; counts against the implementation budget. |
| 4 | Testing | Tester (job `build`) | gemini-3.5-flash-lite | `spec.md`, repo with the change. Withheld: Builder transcript and reasoning. | `test_report.md` | Every AC id appears in a test name in `tests/autose/`; each AC test fails on base and passes on head (red/green; `[regression-only]` ACs exempt from red); full suite passes on head. | Test fault (vacuous/missing/syntax): Tester rewrites (≤3). Code fault: back to stage 3 with failure output (3 attempts), then back to stage 2 once, then stop. |
| 5 | Release | `ship_0` / `ship_1` (script, no LLM) | none | Diff and test report from artifacts. | `pr.md` + PR link | PR open; CI (full pytest + mypy) green on PR head, posted as commit status `autose/ci` (GITHUB_TOKEN pushes do not trigger other workflows). | Stop with reason in `pr.md` and ledger. |
| 6 | Review | Reviewer (job `review_1`, `review_2`) | gemini-3-flash-preview | Raw issue, harness-computed `git diff base...head`, repo at PR head. Withheld: `spec.md`, `design.md`, `test_report.md`, PR body, all worker transcripts. | `review.md` | Verdict JSON valid; approval requires at least one executed command (evidence gate); findings without evidence are dropped. Approve, or 2 rounds used. | `approach` finding returns to stage 2, `code` finding to stage 3 (job `rework_1`), at most twice. Then `finalize`: a human decides. |
